# EVOLVE

## Description

<span class="blue bold">Evolve MIDI Controller</span>

<span class="blue">Generative Systems / MIDI Programming / Interaction Design</span>

<span class="body">Evolve is a custom MIDI controller designed to generate evolving, semi-random musical patterns through algorithmic logic. Programmed in Arduino C++, the system combines arpeggiators, delays, pitch shifts and randomisation tools to create melodies that continuously change over time. The interface encourages experimentation through tactile controls, a rotary encoder menu system and a real-time visualiser that responds to MIDI data. The project explores the relationship between randomness and musical control, translating generative systems into an intuitive and interactive musical instrument.</span>

## Project Title

DESIGNING GENERATIVE MUSICAL SYSTEMS

## Introduction

<span class="body">The project explores how algorithmic logic can be used to create musical patterns that evolve beyond conventional step-based sequencing. By combining controlled randomness with adjustable musical parameters, Evolve allows users to generate sequences that are unpredictable while remaining responsive to their input.

The controller was inspired by the creative possibilities and intuitive workflows of hardware instruments such as the Elektron Digitakt and Conductive Labs NDLR. The aim was to develop an independent instrument that encourages exploration through a balance of automation, hands-on control and real-time feedback.</span>

## Development

INTERFACE & INTERACTION DESIGN

<span class="body">The interface was designed to support quick experimentation, with a clear layout and tactile controls that make the system accessible during use. A custom menu system operated through a rotary encoder allows users to adjust parameters such as pitch range, pattern length and effect settings without requiring a computer.

To improve feedback, I programmed a real-time visualiser that responds to incoming MIDI data, displaying note sequences, rhythms and timing changes as they occur. This visual layer makes the generative process easier to understand and gives users immediate insight into how their adjustments affect the resulting patterns.</span>

## Process

ARDUINO C++ & GENERATIVE LOGIC

<span class="body">The controller was programmed in Arduino IDE using Arduino C++. I developed custom logic for timing, control mapping and real-time pattern generation, alongside musical functions including arpeggiation, delay, pitch shifting and randomisation.

The development process focused on balancing algorithmic variation with user control. Adjustable parameters allow users to influence the behaviour of the generated sequences, while the system introduces changes that create evolving melodic and rhythmic relationships. This combination of software development, MIDI processing and interaction design shaped Evolve into a hands-on exploration of generative music.</span>
